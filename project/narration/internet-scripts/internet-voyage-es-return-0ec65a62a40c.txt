Ahora la respuesta recorre Internet hacia tu ordenador. Cambiamos el dorado por verde para distinguir la vuelta. La respuesta suele ser mayor que la petición y se transporta en muchos segmentos y paquetes. En este ejemplo usamos HTTPS sobre TCP: TCP permite entregar un flujo de bytes ordenado y recuperar pérdidas mediante retransmisiones. La vuelta puede seguir una ruta diferente; usamos el mismo corredor solo para que puedas comparar. Un sitio real también puede usar HTTP tres sobre QUIC.
